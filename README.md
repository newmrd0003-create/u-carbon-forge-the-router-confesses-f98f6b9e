One-line excuse a home Wi-Fi router gives for dropping the connection at the exact climax of a movie — petty, jealous, and smug, not a generic apology. No buffering, bandwidth, or firmware-update joke: the router killed the Wi-Fi on purpose because the hero gets the girl and it only ever gets rebooted.

## Entry

> I killed the Wi-Fi at the climax because the hero gets the girl and I get rebooted - some of us never get a happy ending.

121 characters, single line, UTF-8.

## Run

```sh
python3 main.py
```

Writes the entry to `/output/entry.txt` (and a local `entry.txt` copy for verification), then validates it: 1–200 characters, single line, valid UTF-8. Deterministic — repeated runs produce identical bytes (same sha256).
